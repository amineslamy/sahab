پروژه Sahab از یک معماری اولیه مبتنی بر جاوااسکریپت به یک زیرساخت مقایسه‌پذیر و پرسرعت مبتنی بر Go + PocketBase مهاجرت کرده است.

در ادامه فایل README.md کامل پروژه آماده شده است که وضعیت فعلی، مسیر طی شده و نحوه راه اندازی آن را تشریح می‌کند:

Markdown
# پروژه سحاب (Sahab Go Engine)

این پروژه، هسته جدید و بازنویسی‌شده سیستم مدیریت و پایش داده‌های «سحاب» است که با هدف افزایش سرعت، پایداری، کاهش مصرف منابع و تسهیل مدیریت داده‌ها از معماری اولیه مبتنی بر JS به فریم‌ورک **PocketBase (Go)** منتقل شده است.

---

## 🚀 مسیر طی‌شده پروژه (از کجا به کجا رسیدیم؟)

### ۱. معماری قبلی (مبتنی بر Node.js / JS)
* **واکشی و پردازش داده‌ها:** وابسته به اسکریپت‌های ناهمگام متعددی بود که مدیریت وضعیت (State) را پیچیده می‌کرد.
* **پایگاه داده و پنل مدیریت:** مدیریت ساختار داده‌ها و سطوح دسترسی کاربران دشوارتر بود و به کدهای زیادی در سمت بک‌اند نیاز داشت.

### ۲. معماری فعلی (PocketBase + Go Custom Backend)
* **یکپارچه‌سازی کامل (Single Executable):** تمامی قابلیت‌های دیتابیس (SQLite)، سرویس‌دهی API، پنل مدیریت (Admin Dashboard) و سرو فایل‌های استاتیک فرانت‌اند در قالب یک برنامه Go یکپارچه شد.
* **بهینه‌سازی فاز توسعه (Hot-Reload Friendly):** فایل `main.go` به‌گونه‌ای پیکربندی شده که فایل‌های استاتیک پوشه `pb_public` را مستقیماً از روی دیسک سرو کند. این ویژگی امکان ویرایش زنده کد فرانت‌اند (HTML/JS) بدون نیاز به کامپایل مجدد کد Go را فراهم می‌سازد.
* **اندپوینت‌های اختصاصی (Custom Endpoints):** اضافه شدن مسیرهایی نظیر `/api/custom-change-password` در کد Go برای مدیریت سطح دسترسی دپارتمان‌ها و کاربران بدون دستکاری مستقیم هسته PocketBase.
* **فرانت‌اند سبک و بومی:** بازنویسی کامل بخش مدیریت کاربران (`users.html` و `users.js`) و اتصال مستقیم آن به SDK رسمی PocketBase.
* **مدیریت نسخه (Git Clean Up):** یکپارچه‌سازی شاخه‌های توسعه و مهاجرت کامل به شاخه اصلی `main`.

## 🛠 پیش‌نیازها و ساختار پروژه

### ساختار پوشه‌ها
```text
sahab-go/
├── main.go               # هسته اصلی برنامه به زبان Go
├── pb_data/              # پایگاه داده SQLite و تنظیمات پاکت‌بیس
└── pb_public/            # فایل‌های استاتیک فرانت‌اند
    ├── index.html        # صفحه اصلی
    ├── users.html        # پنل مدیریت کاربران
    ├── css/              # استایل‌ها
    └── js/               # اسکریپت‌ها (users.js, pocketbase.umd.js)
💻 نحوه اجرا در محیط توسعه
برای اجرای پروژه کافی است دستور زیر را در ترمینال پروژه وارد کنید:

Bash
go run main.go serve
پس از اجرا:

فرانت‌اند پروژه: http://127.0.0.1:8090/

مدیریت کاربران: http://127.0.0.1:8090/users.html

پنل مدیریت پاکت‌بیس (Admin UI): http://127.0.0.1:8090/_/

آدرس REST API: http://127.0.0.1:8090/api/
